Sales Performance Dashboard | Power BI
Dashboard de Performance de Vendas, desenvolvido em Power BI, com foco na análise estratégica de faturamento, volume de vendas, devoluções e distribuição regional.

O dashboard foi desenvolvido para:
Monitorar a evolução do faturamento
Comparar desempenho entre anos (YoY)
Acompanhar volume de vendas
Analisar impacto das devoluções
Avaliar distribuição geográfica das vendas
Apoiar decisões orientadas por dados

Principais Indicadores (KPIs)
O painel destaca métricas essenciais para análise executiva:
Faturamento Total
Total de Vendas
Ticket Médio
Quantidade de Devoluções
Valor de Devoluções

Modelo de Dados (Star Schema):
Tabelas Fato:
Vendas 2024
Vendas 2025
Tabelas Dimensão:
Clientes
Lojas
Produtos
Calendário

Análises Possibilitadas:
Identificação de sazonalidade
Comparação de desempenho anual
Avaliação de crescimento
Monitoramento do impacto das devoluções
Análise geográfica das vendas
Identificação de meses de maior performance

Como Utilizar:
Abrir o arquivo .pbix no Power BI Desktop
Interagir com filtros e segmentações
Explorar tendências e comparações
